Política de Privacidad

Última actualización: 11 de julio de 2025

En PancyStudio, tu privacidad es una prioridad. Esta Política de Privacidad tiene como objetivo informarte de manera clara y transparente sobre qué información recopila la instancia oficial de PancyBot ("el Bot", "el Servicio"), por qué la recopilamos y cómo la utilizamos. Esta política se aplica exclusivamente a la instancia oficial operada por PancyStudio Developers.

1. Información que Recopilamos

Para funcionar correctamente, PancyBot necesita recopilar y almacenar una cantidad mínima de información:

a) Datos de Configuración:

  • ID del Servidor de Discord (Guild ID): Para guardar ajustes específicos de tu servidor.
  • ID de Usuario de Discord (User ID): Para gestionar configuraciones personales y perfiles.

b) Datos de Operación y Monitoreo:

  • Logs de Unión y Salida de Servidores: Registramos cuando el Bot es añadido o expulsado de un servidor (nombre e ID del servidor) para fines estadísticos. Estos registros se envían a un canal privado en nuestro servidor de soporte.
  • Informes de Errores (Error Logs): Si ocurre un error, se genera un informe automático que puede contener el ID del servidor y del usuario que causó el error, para ayudarnos a solucionarlo.

c) Información que NO Recopilamos:

PancyBot nunca almacenará de forma permanente el contenido de tus mensajes, tu correo electrónico, o cualquier otra información personal sensible.

2. Cómo Utilizamos tu Información

Utilizamos la información recopilada exclusivamente para el funcionamiento del Bot, para diagnóstico y mejora, y para fines estadísticos. No vendemos, alquilamos ni compartimos tu información personal con terceros.

3. Almacenamiento y Seguridad de Datos

La información de configuración se almacena en una base de datos **MongoDB**, alojada en nuestra propia infraestructura privada. Para garantizar la máxima seguridad, esta base de datos no está expuesta a la red pública de internet; opera con una conexión exclusivamente local, comunicándose únicamente con las instancias de servicio del Bot (Oracle) que residen en la misma tarjeta de red virtual. El acceso a esta infraestructura y a nuestros canales de logs está estrictamente limitado a los desarrolladores autorizados de PancyStudio.

4. Tus Derechos y Control de Datos

Puedes solicitar ver o eliminar todos los datos de configuración asociados a tu ID de usuario o al ID de tu servidor. Para ejercer estos derechos, por favor, contáctanos a través de nuestro servidor de soporte oficial de Discord.

5. Contacto

Si tienes alguna pregunta o inquietud sobre esta Política de Privacidad, no dudes en contactarnos en nuestro servidor de soporte.
